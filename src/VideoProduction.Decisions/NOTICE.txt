VideoProduction.Decisions is optional, application-owned experimental incubation.
It is NOT the released Microsoft.Extensions.AI decision API, or a replacement for
Microsoft.Extensions.AI.Abstractions. No tools are activated by this project.

Adaptation ledger:
  - Contract namespace moved to VideoProduction.Decisions.Experimental.
  - Provider namespaces moved below .Generator, .Julia and .Onnx.
  - Explicit aliases separate provider-domain decisions from contract decisions.
  - Microsoft.Shared guards/diagnostic IDs replaced by small local adapters;
    experimental warning is VPD001 (not an official Microsoft diagnostic).
  - Official public MEAI UsageDetails and AdditionalPropertiesDictionary remain
    package types, never vendored. No private Abstractions package is referenced.
  - AIJsonUtilities defaults replaced by DecisionJsonContext explicit metadata.
    Application state/result metadata must be supplied by each consumer.
    No reflection serializer fallback and no global JSON settings mutation.
  - Added explicit wire metadata context, test friend assembly, hash verifier,
    fixed manifest identity, contract/seam tests and native-only smoke runner.
  - LoadFromDirectory verifies the three pinned assets before any native load.
    Explicit file/stage constructors remain lower-level caller-owned seams.
  - CPU ONNXRuntime remains 1.23.2. The modernized closure pins MEAI Abstractions
    11.0.0 and Tensors 11.0.0 from nuget.org; Directory.Packages.props and lock
    files are authoritative. These supersede the earlier 10.11.0/10.0.12 closure.
  - JuliaTokenizer.cs is new application-owned source, not a copied upstream
    provider file. It derives from Microsoft.ML.Tokenizers.Tokenizer and uses
    Microsoft.ML.Tokenizers 2.0.0 as its abstraction, delegating encoding/decoding
    to Tokenizers.HuggingFace 3.23.1, retained as a production dependency. IDs,
    token strings and scalar offsets originate in HF; scalar coordinates are
    converted to .NET UTF-16 ranges. No BPE or byte-fallback algorithm is owned.
    Complete encoding/counting and decoding are supported. Pipeline overrides,
    token-index queries and truncating encoding explicitly reject.
  - PrepareDecisionInputs stores Microsoft.ML.Tokenizers.Tokenizer; the native
    JuliaDecisionClient also accepts that abstraction and builds the HF adapter
    in LoadFromDirectory. Exact parity covers 48 retained fixture components,
    all 19 decision inputs and additional added-token/mixed-input regressions.
    The earlier bare ML BPE migration blocker remains documented separately.
    Model assets and budgets are unchanged.
  - Restore feed configuration is project-scoped; no global configuration edits.
    NuGet v2 CDN / Microsoft dotnet-public mirror are alternatives when NuGet v3
    TLS is unavailable. Restores must use packages.lock.json in locked mode.
  - SourceHashes.txt records exact original/adapted byte SHA-256 for all 17
    imported source files. No claim is made that adapted files are unmodified.
  - Test-only tracing of actual Julia input batches/native logits substantiates
    state/token framing and ordered output-to-ID mapping with six bounded
    native sanity requests. This makes no video utility or cross-platform claim.
